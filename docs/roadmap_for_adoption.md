# Roadmap for Adoption

The project is designed to become useful before it becomes huge.

## Phase 1: Trustworthy Scaffold

- Clear README with workflow diagram.
- Samplesheet validator.
- Route planner.
- Method radar.
- Evidence-aware audit report.
- MIT license.

## Phase 2: Runnable Minimal Workflow

- Add a tiny public demo dataset.
- Add containerized QC and rRNA split.
- Add HUMAnN functional profiling route.
- Add gene-catalog expression quantification route.
- Add GitHub Actions tests for validators and planners.

## Phase 3: Differentiating Features

- RNA/DNA activity report from paired metagenome and metatranscriptome.
- Orphan-read triage report for unmapped discovery candidates.
- Host-depletion and privacy ledger for host-associated studies.
- Interactive report export.
- Benchmark table comparing accuracy, runtime and interpretability across routes.

## Phase 4: Community Growth

- Issue templates for method requests.
- Example domain packs: human gut, soil/sediment, marine, plant-associated, wastewater.
- A gallery of real analysis reports.
- Documentation pages that teach interpretation, not only commands.
